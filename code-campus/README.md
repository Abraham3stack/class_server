# Code Campus Frontend

This folder contains the frontend application only.

Stack:

- React
- Vite
- Tailwind CSS v4
- shadcn/ui
- Lucide icons

## Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Purpose

This frontend renders the board member appraisal form UI and submits the completed payload to the Express backend at `http://localhost:5000/api/forms`.
